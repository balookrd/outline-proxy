# Changelog — outline-windows

English version: [CHANGELOG.md](CHANGELOG.md).

`outline-windows` — нативный клиент Outline Proxy для платформы Windows (x86_64),
построенный на стеке Tauri v2, Svelte 5 и Rust. Работает поверх сетевого ядра
`outline-client` и управляет системным прокси, Wintun TUN-адаптером, маршрутами,
профилями и подписками.

Формат следует [Keep a Changelog](https://keepachangelog.com/).

## [1.9.2] - 2026-11-21

### Добавлено

- **Встроенная система проверки и установки обновлений (In-app Updater)**:
  - **Интерактивный футер с версией**: отображает текущий канал, версию и хэш
    коммита (`nightly · v1.9.2 (971282b6)` для nightly-сборок или `v1.9.2` для релизов).
    По клику запускается ручная проверка обновлений с индикацией состояний:
    `проверка обновлений…` → `актуальная версия` (на 4 сек) или `доступно <label>`
    с открытием окна установки.
  - **Фоновая тихая проверка**: автоматический опрос релизов через 5 секунд после
    старта приложения. При наличии новой версии статус футера меняется на
    `доступно <label> — нажмите` без блокировки интерфейса пользователя.
  - **Каналы обновлений**: поддержка каналов `nightly` (тег `windows-nightly` в
    GitHub Releases с сопоставлением хэша коммита) и `release` (теги `windows-v*` с
    поиском наивысшей версии по SemVer).
  - **Диалог установки `UpdateModal`**: окно с отображением версии, описания изменений
    (release notes) и интерактивным прогресс-баром скачивания в процентах.
  - **Потоковая верификация SHA-256**: загрузка манифеста `SHA256SUMS.txt`,
    потоковый расчёт дайджеста SHA-256 (`ring::digest::SHA256`) во время скачивания
    архива и автоматическое прерывание с удалением файла при любом расхождении хэша.
  - **Защита от Zip Slip**: безопасная распаковка во временный staging-каталог с
    валидацией путей каждого элемента через `zip_file.enclosed_name()`.
  - **Бесшовная замена файлов (`apply_update.cmd`)**: отсоединённый командный скрипт
    `outline_update_<pid>.cmd`, запускаемый в фоновом режиме
    (`CREATE_NO_WINDOW | DETACHED_PROCESS`), ожидающий завершения процесса приложения
    по PID, заменяющий файлы (`xcopy /Y /Q /E`), запускающий обновленный `OutlineProxy.exe`
    и очищающий временные данные.
  - **Автоматический реконнект туннеля (`reconnect_after_update`)**: если туннель был
    поднят до обновления, перед перезапуском в настройках сохраняется флаг
    `reconnect_after_update = true`. При новом старте приложение сбрасывает флаг и
    автоматически восстанавливает соединение с активным профилем через 1 секунду.

## [1.9.0] - 2026-08-24

### Добавлено

- **Первый релиз нативного клиента для Windows 10/11 (x86_64)**:
  - Графический интерфейс на Svelte 5 (Runes) + Tailwind CSS на базе Tauri v2.
  - Два режима работы: SOCKS5 (системный прокси WinInet / Registry) и TUN (полный L3 VPN через драйвер Wintun 0.14.1 и Windows IP Helper API).
  - Управление профилями серверов: импорт `vless://`, `ss://`, `outline://`, управление подписками по HTTPS.
  - Иконка в системном трее Windows с контекстным меню быстрого управления.
  - Мониторинг сетевой активности и трафика в реальном времени через control API `outline-ws-rust`.
  - Скрипт сборки и кросс-компиляции `scripts/package-windows.sh`.
