# Спецификация: Паритет интерфейса macOS с Android (Статистика сессии, протоколы TCP/UDP, разделение серверов и настроек)

## 1. Цели и мотивация

Текущая реализация приложения Outline Proxy для macOS (`macos/`) имеет ряд расхождений с Android-версией:
1. **Имя подписки на главной карточке:** Если профиль называется «Подписка», код автоматически извлекал первый хост из TOML-конфигурации (`cloud1.beerloga.su`) и выводил субдомен `cloud1`, что сбивало с толку пользователя (в настройках профиль назывался «Подписка», а на дашборде — «cloud1»).
2. **Статистика сессии (`StatsStrip`):** На главном экране macOS отображались режим (SOCKS5/TUN) и упрощенный протокол (например, `VLESS/H3`). В то же время Android отображает полноценную тройную полосу метрик: длительность сессии (`ЧЧ:ММ:СС`), объём переданного трафика (`↑ uplink` и `↓ downlink`), и независимый статус протоколов/носителей для `TCP` и `UDP` (включая H3, H2 и H1).
3. **Смешение настроек и управления серверами:** В окне `SettingsWindowController` объединены системные параметры (режим SOCKS5/TUN, тумблер TCP-only, helper для TUN, тема) и таблица профилей серверов. При клике на карточку сервера или на настройки открывалось одно и то же перегруженное окно.

Цель данной работы — привести macOS-приложение к единому стандарту с Android:
- На карточке выводить прямое имя профиля (`profile.name`).
- Реализовать полосу метрик в стиле Android: таймер сессии, счетчики трафика `↑`/`↓`, строки носителей `TCP` и `UDP` (с поддержкой H1/H2/H3).
- Разделить управление серверами и настройки приложения на два независимых специализированных окна: `ServersWindowController` (управление серверами) и `SettingsWindowController` (системные параметры).

## 2. Архитектура и изменения в компонентах

### 2.1. Отображение имени профиля (`ServerProfile.swift`)

В [`ServerProfile.swift`](macos/Sources/OutlineProxy/Core/Models/ServerProfile.swift):
- Свойство `displayName` упрощается:
  - Если задано `name` и оно не пустое, всегда возвращается `name` (в том числе «Подписка» или любое имя, заданное пользователем).
  - Если `name` пустое:
    - Для подписок возвращается «Подписка».
    - Для прямых ссылок (`link`) возвращается хост из ссылки или `transport.uppercased() + " сервер"`.
    - Fallback: «Без названия».
  - Устраняется эвристика парсинга `cachedToml` для замены названия «Подписка» на имя первого попавшегося хоста (`cloud1`).

### 2.2. Полоса статистики сессии (`StatsStrip`) в `MainWindowController.swift`

В карточке статуса при активном подключении (`AppState.shared.status == .connected`) отображается трехколоночный блок:

1. **Колонка 1 — Длительность:**
   - Иконка: `clock` (SF Symbols) / таймер.
   - Заголовок: `ДЛИТЕЛЬНОСТЬ`.
   - Значение: `00:00:00` (динамический таймер с секундами).
   - Подпись: `чч:мм:сс`.

2. **Колонка 2 — Трафик (Uplink / Downlink):**
   - Иконка: `waveform` / `chart.bar` (аналог `GraphicEq` в Android).
   - Заголовок: `ТРАФИК`.
   - Значение 1: `↑ <uplink>` (отправленные байты за текущую сессию).
   - Значение 2: `↓ <downlink>` (принятые байты за текущую сессию).
   - Форматирование: человекочитаемые единицы (Б, КБ, МБ, ГБ).
   - **Сбор метрик:**
     - В режиме **TUN**: использование системного вызова BSD `getifaddrs` для интерфейса `utun` (чтение `ifi_obytes` и `ifi_ibytes`). На момент подключения фиксируется базовая точка отсчета (`baseline`), и отображается дельта с обновлением каждую секунду (вместе с таймером длительности).
     - В режиме **SOCKS5**: опрос счетчиков байт через опрос сетевых соединений или встроенный эндпоинт `/metrics` (`outline_ws_bytes_total`), либо сетевой счетчик хоста.

3. **Колонка 3 — Протокол:**
   - Иконка: `waveform.path.ecg` / `heart.text.square` (аналог `MonitorHeart` в Android).
   - Заголовок: `ПРОТОКОЛ`.
   - Значение 1: `TCP  <Семейство>/<Носитель>`
     - Например: `TCP  VLESS/XHTTP/H3`, `TCP  VLESS/WS/H2`, `TCP  VLESS/WS/H1`, `TCP  SS/WS/H1`.
   - Значение 2: `UDP  <Семейство>/<Носитель>`
     - Например: `UDP  VLESS/XHTTP/H3` или `UDP  —` (прочерк), если включен режим «Только TCP» (`tcpOnly == true`), при котором QUIC/H3 и UDP 443 отключены.
   - Определение носителя:
     - Анализ активного профиля / сгенерированного конфига: семейство транспорта (`VLESS`, `SS`), режим (`xhttp`, `ws`), и уровень протокола HTTP (`H3`, `H2`, `H1`) с учетом настройки `tcpOnly`.

### 2.3. Разделение экранов: Серверы (`ServersWindowController`) и Настройки (`SettingsWindowController`)

#### Новый контроллер `ServersWindowController.swift`
- Отдельное окно `NSWindowController` с заголовком **«Серверы и подписки»**.
- Размер: $680 \times 440$ pt, с поддержкой изменения размера.
- Содержимое:
  - Таблица серверов (`NSTableView`):
    - Колонка `Active`: индикатор «● АКТИВЕН» для текущего выбранного профиля.
    - Колонка `Name`: название профиля (`profile.name`).
    - Колонка `Type`: тип подключения (`Подписка`, `VLESS`, `SS`, с пометкой `(TCP)`, если активен режим `tcpOnly`).
    - Колонка `Link`: URL подписки или ссылка на сервер.
  - Нижняя панель действий:
    - Кнопка «Сделать активным» (выбирает профиль в `ProfileStore`, при активном подключении переподключает на лету).
    - Кнопка «+ Добавить сервер или подписку» (диалог добавления по ссылке `vless://`, `ss://` или URL подписки `https://`).
    - Кнопка «Удалить» (с подтверждением).
- Точки входа:
  - Клик по статусной карточке на главном экране (`MainWindowController`).
  - Клик по стрелке `chevronButton` на главной карточке.
  - Клик по кнопке «+ Добавить сервер» на главном экране.
  - Пункт меню «Серверы...» в статусном меню Menu Bar (`StatusMenuController`).

#### Рефакторинг `SettingsWindowController.swift`
- Окно переименовывается / фокусируется исключительно на **системных настройках**:
  - Заголовок: **«Настройки — Outline Proxy»**.
  - Размер: $520 \times 420$ pt (компактное, без пустой таблицы).
- Содержимое:
  1. **Режим перехвата трафика (`ProxyMode`):**
     - Выпадающий список или радиокнопки: `SOCKS5 (Системный прокси)` / `TUN (VPN для всей системы)`.
     - Пояснительный текст для каждого режима.
  2. **Режим «Только TCP» (без HTTP/3 / QUIC):**
     - Переключатель (Switch) `NSSwitch`.
     - Пояснение: «Отключает QUIC/H3 (UDP 443) и переводит туннели на HTTP/2 / HTTP/1.1 для сетей с блокировкой UDP».
  3. **Режим TUN: запуск без пароля:**
     - Статус конфигурации sudoers (`sudoers.d`).
     - Кнопка «Настроить запуск без пароля» / «Настроено».
  4. **Тема оформления:**
     - Выбор темы: Системная / Светлая / Тёмная.
- Таблица серверов и кнопки управления профилями полностью удаляются из этого окна.
- Точки входа:
  - Кнопка «Настройки» в Quick Links на главном экране.
  - Сочетание клавиш `⌘,` (Preferences).
  - Пункт «Настройки...» в Status Bar меню и в главном меню приложения.

## 3. План тестирования и верификации

1. **Компиляция и линковка:**
   - `swift build` в каталоге `macos/` проходит без ошибок и предупреждений.
2. **Проверка отображения имени профиля:**
   - Профиль со значением `name = "Подписка"` отображает на карточке главного экрана крупно «Подписка», а не имя узла `cloud1`.
3. **Проверка полосы статистики:**
   - После подключения появляются 3 колонки:
     - Длительность тикает каждую секунду (`00:00:01`, `00:00:02`, ...).
     - Трафик отображает `↑` и `↓` с корректными единицами измерения.
     - Протоколы выводят две строки: `TCP  VLESS/XHTTP/H3` (или H2/H1) и `UDP  VLESS/XHTTP/H3` (или `UDP  —` при `tcpOnly = true`).
4. **Проверка разделения окон:**
   - Клик по карточке сервера открывает окно «Серверы и подписки».
   - Клик по шестеренке / Quick Link «Настройки» открывает чистое окно настроек.
   - Окна не конфликтуют, поддерживают переключение тем оформления.
5. **Проверка регрессий в CI-гейте:**
   - Запуск `cargo fmt`, `cargo clippy`, `cargo test` по workspace монорепозитория.
