# Рандомизация GREASE версии и позиции в QUIC Version Negotiation под Caddy (quic-go)

План устранения статической сигнатуры Quinn в пакетах Version Negotiation (VN).
Цель — устранить расхождение сетевого отпечатка `outline-ss-rust` при активном зондировании неподдерживаемыми версиями QUIC:
- В upstream Quinn: reserved версия всегда равна `0x0a1a_2a3a` и всегда записывается первой.
- В эталоне Caddy (`quic-go`): reserved версия выбирается случайно по маске `0x?a?a?a?a` (RFC 9000 §15) и вставляется на случайную позицию в списке поддерживаемых версий.

---

## 1. Контекст

Сервер отправляет Version Negotiation только при получении Initial-пакета с неизвестной версией (например, активные сетевые сканеры).
В настоящее время Quinn всегда отправляет:
`[0x0a1a2a3a, 0x00000001]`

Caddy (`quic-go`) генерирует случайную reserved-версию и вставляет её в случайное место:
`[0x?a?a?a?a, 0x00000001]` или `[0x00000001, 0x?a?a?a?a]`.

---

## 2. Архитектурное решение

В `vendor/quinn-proto/src/endpoint.rs`:
1. Генерировать `reserved_version`:
   ```rust
   let mut reserved_version = (self.rng.random::<u32>() & 0xf0f0_f0f0) | 0x0a0a_0a0a;
   if reserved_version == version {
       reserved_version ^= 0x1000_0000;
   }
   ```
2. Выбирать случайный индекс `grease_index` из диапазона `0..=self.config.supported_versions.len()`.
3. Записывать версии в буфер так, чтобы `reserved_version` оказалась на позиции `grease_index`.

---

## 3. План тестирования

1. Интеграционный тест в `bins/outline-ss-rust/src/server/tests/tcp_caddy_emulation.rs`:
   - Отправить на UDP-порт H3 сервера Initial-пакет с фиктивной версией (например, `0x1a2b3c4d`).
   - Принять ответный пакет Version Negotiation.
   - Проверить, что:
     - Длина списка версий = 2.
     - Присутствует `0x00000001` (QUIC v1).
     - Присутствует версия `v`, у которой для каждого байта `(b & 0x0f) == 0x0a`.
     - При нескольких последовательных запросах позиция и значение `v` меняются.
2. Прогон полного локального CI-гейта.
