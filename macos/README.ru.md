# Outline Proxy — клиент для macOS

English version: [README.md](README.md).

Нативный клиент для macOS (Apple Silicon и Intel) в строке меню. Работает поверх
ядра `outline-ws-rust` (VLESS, Shadowsocks AEAD, WebSocket, HTTP/3, padding,
failover): Swift-приложение запускает ядро дочерним процессом и управляет
вокруг него системным прокси, профилями и подписками.

Интерфейс только на русском; ниже надписи интерфейса приведены так, как они
выглядят в приложении.

## Возможности

- Два режима работы:
  - SOCKS5 (системный прокси). Работает без root. Ядро слушает
    `127.0.0.1:1080`, приложение прописывает его SOCKS-прокси активных сетевых
    служб через `/usr/sbin/networksetup`. Им пользуются только приложения,
    которые учитывают системные настройки прокси.
  - TUN (полный L3 VPN). Трафик идёт через интерфейс macOS `utun`
    (`com.apple.net.utun_control`). Хелпер `tun-runner.sh` запускает ядро от
    root, добавляет host-маршруты до серверов (чтобы туннель не заворачивал сам
    себя) и маршруты по умолчанию через peer `utun` `10.0.85.1`. Так
    перехватывается трафик всех процессов, включая консольные утилиты и DNS.
- Запуск TUN без пароля. Кнопка **Настроить в 1 клик...** в окне «Настройки»
  один раз запрашивает пароль администратора, копирует `tun-runner.sh` в
  `/Library/Application Support/OutlineProxy/tun-runner.sh` и пишет правило
  `NOPASSWD` для этого пути в `/etc/sudoers.d/outline-proxy`. После этого
  подключение и отключение в режиме TUN проходят без диалога ввода пароля.
  Кнопка **Удалить правило** в той же карточке удаляет его.
- Меню в строке состояния: подключение/отключение, статус, выбор режима и
  сервера.
- Режим «Только TCP» (без HTTP/3) — переключатель в окне «Настройки» и в меню
  строки состояния. Он переписывает конфиг: носители `xhttp_h3` / `ws_h3`
  становятся `xhttp_h2` / `ws_h2`, а из `alpn=` в share-ссылках убирается `h3`.
  Нужен в сетях, где UDP 443 заблокирован или троттлится: без него ядро ждёт
  тайм-аута рукопожатия H3, прежде чем откатиться на H2. Переключение при
  поднятом туннеле переподключает его.
- Профили и подписки: импорт share-ссылок `vless://` и `ss://` (в том числе
  обёрнутых в `outline://`), в том числе из буфера обмена, и URL подписок
  (`https://`; парсер принимает и `http://`), которые перезапрашиваются
  автоматически.
- Главное меню (Файл, Правка, Вид, Окно, Справка) с сочетаниями: `Cmd+Q`
  (выход со снятием системного прокси и маршрутов), `Cmd+W` (закрыть окно),
  `Cmd+,` (настройки), `Cmd+O` (главное окно), `Cmd+L` (журнал), `Cmd+Shift+C`
  (подключить/отключить), `Cmd+M` (свернуть), `Cmd+H` (скрыть), а в текстовых
  полях — `Cmd+Z`/`Cmd+Shift+Z`, `Cmd+X`, `Cmd+C`, `Cmd+V`, `Cmd+A`.
- Окно журнала с выводом ядра и кнопкой **Копировать всё**.
- Очистка при выходе. При завершении и по SIGINT/SIGTERM приложение снимает
  системный прокси, а в режиме TUN — маршруты. После аварийного завершения
  оставшийся прокси `127.0.0.1:1080` выключается при следующем запуске, а
  `tun-runner.sh` перед стартом нового туннеля удаляет оставшиеся маршруты.

## Требования для сборки

- macOS 13.0 (Ventura) или новее (`LSMinimumSystemVersion`, `Package.swift`).
- Swift 5.9+ (`swift-tools-version: 5.9`). Достаточно Xcode Command Line Tools,
  полный Xcode не нужен.
- Rust stable 1.88+: workspace использует edition 2024 и let-chains.
  [проверить: минимальная версия Rust, `rust-version` в `Cargo.toml` не задан]

## Сборка и запуск

Соберите бандл приложения:

```bash
./macos/scripts/package-app.sh
```

Скрипт:

1. Собирает `outline-ws-rust` в release (`cargo build -p outline-ws-rust --release`).
2. Собирает Swift-приложение (`swift build -c release`).
3. Формирует `macos/dist/Outline Proxy.app`: Swift-бинарь в
   `Contents/MacOS/OutlineProxy`; ядро, `tun-runner.sh` и графические ресурсы в
   `Contents/Resources/`; `Info.plist` с версией, коммитом, каналом и датой
   сборки, которые прописывает `PlistBuddy`.
4. Подписывает бандл ad-hoc (`codesign --force --deep --sign -`).

Запуск:

```bash
open "macos/dist/Outline Proxy.app"
```

В строке меню появится иконка щита.

## Переключение режимов работы

- Через меню строки состояния: нажмите на иконку щита и в секции **Режим
  работы:** выберите **SOCKS5 (Системный прокси)** или **TUN (Полный VPN)**.
- Через настройки (`Cmd+,`): выберите режим в выпадающем списке вверху окна.

Если туннель поднят, приложение отключается и примерно через 0,6 с
подключается заново в новом режиме.

## Установка из DMG

Скачайте `OutlineProxy-*-macOS-Universal.dmg` из GitHub Releases
(`macos-nightly` или тег `macos-v*`), откройте образ и перетащите Outline Proxy в
«Программы».

При первом запуске macOS, скорее всего, откажется открывать приложение и
предложит переместить его в Корзину. Браузер помечает скачанные файлы атрибутом
`com.apple.quarantine`, пометка переходит на приложение, скопированное из DMG,
а Gatekeeper проверяет каждое помеченное приложение. Сборка подписана ad-hoc,
без Apple Developer ID и нотаризации, поэтому проверку не проходит. Разрешить
её можно одним из двух способов:

- Через Системные настройки: закройте окно кнопкой **Готово**, откройте
  **Системные настройки → Конфиденциальность и безопасность**, внизу найдите
  сообщение про Outline Proxy, нажмите **Всё равно открыть** и подтвердите
  паролем. В свежих версиях macOS обход через правый клик → **Открыть** убран,
  так что из интерфейса остаётся только этот путь.
- Через Терминал: снимите пометку с установленного приложения:

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Outline Proxy.app"
  ```

Это нужно один раз — для приложения, установленного из DMG, который скачал
браузер. Обновления, которые ставит само приложение (см. ниже), скачивают DMG
без браузера, пометки не получают и открываются без этого окна.

## Обновления

Приложение обновляется из GitHub Releases по своему каналу сборки. Релизная
сборка (тег `macos-v*`) переходит на самую новую версию `macos-v*`.
Nightly-сборка следит за плавающим тегом `macos-nightly` и обновляется, когда
опубликованный DMG собран из другого коммита.

- Проверка: нажмите на строку версии внизу главного окна или выберите
  **Проверить обновления...** в меню строки состояния. Кроме того, не чаще раза
  в 24 часа идёт фоновая проверка: найденная сборка только появляется в подвале
  и в меню, без вашей команды ничего не скачивается.
- Установка: в окне видны заметки к релизу и кнопка **Установить и
  перезапустить**. Приложение скачивает DMG в обход системного прокси (в режиме
  SOCKS5 загрузка не зависит от туннеля), сверяет его с `SHA256SUMS.txt`
  релиза, распаковывает рядом с установленным бандлом, проверяет подпись и
  идентификатор, завершается, подменяет бандл и запускается заново. Если туннель
  был поднят, он переподключится сам (в режиме TUN без запроса пароля — только
  если настроено правило sudoers). Если подмена не удалась, возвращается старый
  бандл. Журнал подмены — `~/Library/Logs/OutlineProxy/update.log`.
- Ручной вариант (как на Android): если бандл нельзя заменить на месте (нет
  прав на запись в его каталог, приложение запущено из копии App Translocation,
  разработческий запуск не из `.app`) или установка на месте не удалась,
  проверенный DMG сохраняется в `~/Downloads` и открывается в Finder —
  перетащите Outline Proxy в «Программы» с заменой.

Сборки без этого механизма (nightly `4c7821c4` и старше) один раз придётся
обновить вручную.

## Сборка DMG-образа

`package-dmg.sh` собирает приложение (если не сказано иное) и упаковывает его в
сжатый (`UDZO`) DMG с ярлыком `/Applications` для установки перетаскиванием:

```bash
# Под архитектуру хоста:
./macos/scripts/package-app.sh --dmg
# или напрямую:
./macos/scripts/package-dmg.sh

# Universal-бинарь (arm64 + x86_64, склейка через lipo):
./macos/scripts/package-dmg.sh --arch universal
```

Опции `package-dmg.sh`:

| Опция | По умолчанию | Что делает |
|---|---|---|
| `--arch <native\|universal\|aarch64\|x86_64>` | `native` | Целевая архитектура обоих бинарей |
| `--version <версия>` | `version` из `bins/outline-ws-rust/Cargo.toml` | Версия в имени DMG |
| `--output-dir <каталог>` | `macos/dist` | Куда писать DMG; относительный путь берётся от корня репозитория |
| `--dmg-name <имя>` | см. ниже | Точное имя DMG-файла |
| `--app-path <путь>` | — | Взять уже собранный `.app`; включает `--skip-build` |
| `--skip-build` | — | Не собирать; упаковать готовый `macos/dist/Outline Proxy.app` |

Имена по умолчанию: `OutlineProxy-v<версия>-macOS.dmg` для `native`,
`OutlineProxy-v<версия>-macOS-Universal.dmg` для `universal`,
`OutlineProxy-v<версия>-macOS-<arch>.dmg` для остальных. Контрольная сумма
пишется рядом как `<имя-dmg>.sha256`.

## CI и релизы

| Workflow | Запуск | Что делает |
|---|---|---|
| `.github/workflows/ci.yml`, джоб `macos` | Каждый pull request и push в `main` | `package-dmg.sh --arch native`; выкладывает DMG артефактом `OutlineProxy-macOS-preview`, хранится 7 дней |
| `.github/workflows/macos-nightly-release.yml` | Push в `main`, затрагивающий `macos/**`, `bins/outline-ws-rust/**`, `crates/**`, `vendor/**`, `Cargo.toml`, `Cargo.lock`, `.cargo/**`; ручной запуск | Собирает `OutlineProxy-nightly-<sha8>-macOS-Universal.dmg` и обновляет плавающий релиз `macos-nightly` |
| `.github/workflows/macos-tag-release.yml` | Push тега `macos-v*` | Собирает `OutlineProxy-v<версия>-macOS-Universal.dmg`, пишет `SHA256SUMS.txt`, генерирует заметки к релизу через `git-cliff` и публикует релиз на GitHub |
| `.github/workflows/macos-release.yml` | Вручную (`workflow_dispatch`) | Поднимает версию и коммитит `release: cut macos-v...` в `main` |
