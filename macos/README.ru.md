# Outline Proxy — клиент для macOS

Нативный клиент для macOS (Apple Silicon и Intel), работающий в строке меню (Menu Bar). Переиспользует полное ядро `outline-ws-rust` (VLESS, Shadowsocks AEAD, WebSocket, HTTP/3, padding, failover).

## Возможности

- **Два режима работы с переключением в один клик:**
  - **SOCKS5 (Системный прокси):** Работает без прав root и без запросов паролей администратора. Автоматически настраивает системный прокси macOS через `networksetup`. Подходит для браузеров и приложений, поддерживающих системные настройки.
  - **TUN (Полный L3 VPN):** Полноценный перехват всего системного сетевого стека через встроенный в ядро macOS BSD-интерфейс `utun` (`com.apple.net.utun_control`). Перенаправляет весь трафик Mac (включая консольные утилиты, игры, фоновые демоны, DNS).
- **Беспарольный запуск TUN в 1 клик:**
  - В окне «Настройки» доступна кнопка **«Настроить в 1 клик...»**, которая однократно запрашивает системный пароль администратора и создает безопасное изолированное правило в `/etc/sudoers.d/outline-proxy` для скрипта-хелпера `tun-runner.sh`.
  - После настройки запуск и остановка полноэкранного L3 VPN происходят мгновенно в один клик без появления системных диалогов ввода пароля. Правило можно в любой момент удалить в том же окне настроек.
- **Меню в строке состояния (Menu Bar):** Быстрое подключение/отключение в один клик, индикатор статуса, мгновенный выбор режима работы и активного сервера.
- **Поддержка профилей и подписок:** Импорт ссылок `vless://`, `ss://`, `outline://` (включая вставку из буфера обмена), а также автообновление конфигураций по URL (HTTPS).
- **Полноценное главное меню macOS и стандартные горячие клавиши:** Системное меню приложения в строке меню (Файл, Правка, Вид, Окно, Справка) с поддержкой стандартных шорткатов: `Cmd+Q` (чистое завершение с автоматическим сбросом системных настроек и маршрутов), `Cmd+W` (закрытие активного окна), `Cmd+,` (настройки), `Cmd+O` (главное окно), `Cmd+L` (журнал), `Cmd+Shift+C` (быстрое подключение/отключение), а также полная поддержка буфера обмена и отмены действий в текстовых полях (`Cmd+Z`, `Cmd+C`, `Cmd+V`, `Cmd+A`).
- **Окно логов реального времени:** Просмотр событий и диагностика соединения с поиском и копированием.
- **Чистое завершение:** Автоматический сброс системного прокси и очистка маршрутов ядра при выходе или аварийном завершении приложения.

## Требования для сборки

- macOS 13.0 (Ventura) или новее.
- Swift 5.9+ (достаточно стандартных Xcode Command Line Tools, полный Xcode не требуется).
- Rust 1.75+ (включая Edition 2024).

## Сборка и запуск

Сборка приложения выполняется единым скриптом:

```bash
./macos/scripts/package-app.sh
```

Скрипт выполнит:
1. Релизную компиляцию Rust-ядра `outline-ws-rust`.
2. Релизную компиляцию Swift-приложения.
3. Формирование бандла `macos/dist/OutlineProxy.app` с вложенным ядром, вспомогательным скриптом маршрутизации `tun-runner.sh` и `Info.plist` (`LSUIElement = true`).
4. Ad-hoc подпись приложения для запуска на текущем Mac.

### Запуск приложения:

```bash
open macos/dist/OutlineProxy.app
```

В строке меню macOS появится иконка щита `Outline Proxy`.

## Переключение режимов работы

1. **Через меню строки состояния:**
   Нажмите на иконку щита в строке меню -> в секции «Режим работы» выберите:
   - `✓ SOCKS5 (Системный прокси)`
   - `  TUN (Полный VPN)`
2. **Через настройки:**
   Нажмите «Настройки...» (или `Cmd+,`) и выберите нужный режим в выпадающем списке верхнего баннера.
   Если туннель уже был активен, приложение автоматически переподключится в новом режиме.

## Сборка DMG-образа диска

Для упаковки приложения в сжатый `.dmg` образ с ярлыком `/Applications` для установки Drag-and-Drop:

```bash
# Локальная сборка DMG для текущей архитектуры (native):
./macos/scripts/package-app.sh --dmg
# или напрямую через скрипт упаковщика:
./macos/scripts/package-dmg.sh

# Сборка универсального DMG (Universal Binary: Apple Silicon + Intel):
./macos/scripts/package-dmg.sh --arch universal
```

Готовый файл и контрольная сумма сохраняются в `macos/dist/OutlineProxy-v<версия>-macOS.dmg` и `.sha256`.

## Непрерывная интеграция (GitHub Actions CI)

Сборка образа macOS автоматизирована в репозитории:

- **CI Merge Gate (`.github/workflows/ci.yml`):** При каждом Pull Request и коммите в ветку `main` собирает превью-образ `.dmg` и публикует его в артефакты сборки `OutlineProxy-macOS-preview` (хранится 7 дней).
- **Nightly Releases (`.github/workflows/macos-nightly-release.yml`):** При изменениях клиентского кода в `main` автоматически собирает Universal DMG и обновляет скользящий релиз `macos-nightly`.
- **Релизные теги (`.github/workflows/macos-tag-release.yml`):** Пуш тега `macos-v*` автоматически собирает релизный Universal DMG, вычисляет `SHA256SUMS.txt`, формирует changelog через `git-cliff` и публикует релиз на GitHub Releases.
- **Подготовка релиза (`.github/workflows/macos-release.yml`):** Ручной запуск через `workflow_dispatch` для бампа версии и создания коммита `release: cut macos-v...`.
